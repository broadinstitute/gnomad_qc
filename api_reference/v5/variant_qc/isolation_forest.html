gnomad_qc.v5.variant_qc.isolation_forest

Script to run the GATK isolation forest variant QC model on an AS-annotated sites VCF.

SNPs and INDELs are modeled separately (GATK --mode): for each variant type the workflow runs ExtractVariantAnnotations -> TrainVariantAnnotationsModel (PYTHON_IFOREST) -> ScoreVariantAnnotations (scattered over intervals). The two per-mode scored VCFs are merged into a single result HT in the --load-iforest step.

usage: gnomad_qc.v5.variant_qc.isolation_forest.py [-h] [-o]
                                                   [--environment {rwb,batch}]
                                                   --model-id MODEL_ID
                                                   [--test]
                                                   [--test-chrom TEST_CHROM [TEST_CHROM ...]]
                                                   [--test-on-v4]
                                                   [--export-v4-test-vcf]
                                                   [--export-only]
                                                   --batch-billing-project
                                                   BATCH_BILLING_PROJECT
                                                   --gcp-billing-project
                                                   GCP_BILLING_PROJECT
                                                   [--batch-suffix BATCH_SUFFIX]
                                                   [--app-name APP_NAME]
                                                   [--driver-cores DRIVER_CORES]
                                                   [--driver-memory DRIVER_MEMORY]
                                                   [--worker-cores WORKER_CORES]
                                                   [--worker-memory WORKER_MEMORY]
                                                   [--gatk-image GATK_IMAGE]
                                                   [--scatter-count SCATTER_COUNT]
                                                   --out-vcf-name OUT_VCF_NAME
                                                   [--hyperparameters-json HYPERPARAMETERS_JSON]
                                                   [--transmitted-singletons]
                                                   [--sibling-singletons]
                                                   [--adj] [--load-iforest]
                                                   [--load-only]
                                                   [--n-partitions N_PARTITIONS]
                                                   [--header-path HEADER_PATH]
                                                   [--array-elements-required]

Named Arguments

-o, --overwrite

Whether to overwrite existing outputs (with –load-only, only overwrite the result HT).

Default: False

Compute environment.

Default: “batch”

--model-id

Model ID for the isolation forest run. Must start with ‘if’ (e.g. if_test1).

testing options

--test

Filter to –test-chrom and use a small scatter count for testing.

Default: False

--test-chrom

Contig(s) to score under –test/–test-on-v4. Must match the contigs in the test info VCF.

Default: [‘chr21’]

--test-on-v4

Use gnomAD v4 sites/true-positive VCFs as inputs (v5 data unavailable).

Default: False

--export-v4-test-vcf

Export the v4 split info HT filtered to –test-chrom as the –test-on-v4 sites VCF. Requires –test-on-v4.

Default: False

--export-only

Stop after –export-v4-test-vcf instead of continuing to the Batch.

Default: False

Default: False

--adj

Default: False

Merge the scored VCFs into a variant QC result HT.

gnomad_qc.v5.variant_qc.isolation_forest.score_variant_annotations_job(b, mode, sites_only_vcf, features, extracted_vcf, model, resource_args, interval, idx, out_root, gatk_image, gcp_billing_project)[source]

Run GATK ScoreVariantAnnotations for one variant type mode over one interval.

Parameters:

  • b (Batch) – Batch to add the job to.

  • mode (str) – Variant type mode, ‘SNP’ or ‘INDEL’.

  • sites_only_vcf (str) – AS-annotated sites-only input VCF.

  • features (List[str]) – Features for this mode (must match the trained model).

  • extracted_vcf (ResourceFile) – Extracted training/calibration VCF from the extract step.

  • model (Union[ResourceGroup, str]) – --model-prefix: the trained model ResourceGroup from the train job, or a prefix string built from a read-in group (see isolation_forest_workflow).

  • resource_args (str) – GATK --resource args for the labeled sets.

  • interval (ResourceFile) – Interval file to restrict scoring to.

  • idx (int) – Shard index, used to identify the job in the Batch.

  • out_root (str) – Output prefix (files written as {out_root}.*).

  • gatk_image (str) – GATK docker image.

  • gcp_billing_project (str) – GCP billing project for requester-pays buckets.

Return type:

Job

Returns:

Job with output ResourceGroup output_score.

Note

GATK traversal returns every record overlapping the shard interval, and the default output mode (ANYWHERE) writes all of them, so a deletion straddling a shard boundary is emitted by both neighbors. --variant-output-filtering STARTS_IN writes a record only if its start is in the interval, making emission exactly-once across shards. It also makes -XL start-based, which is the definition reconcile_scored_sites uses.

gnomad_qc.v5.variant_qc.isolation_forest.check_run_config(run_prefix, config, overwrite, write)[source]

Guard reuse of outputs under run_prefix against a changed run configuration.

Extract/model/score outputs are reused by path alone, so a rerun with different contigs, scatter count, or inputs would silently reuse region- or split-mismatched files. Compare against the config recorded by the first run and raise on any difference unless overwrite.

Parameters:

  • config (Dict[str, Any]) – Current run configuration.

  • overwrite (bool) – Whether outputs are being overwritten. Skips the comparison only in the Batch step; –load-only reuses whatever is under run_prefix (its –overwrite only replaces the result HT), so it always compares.

  • write (bool) – Whether to record config (the Batch step; the load step only compares).

None

gnomad_qc.v5.variant_qc.isolation_forest.export_exclusion_intervals(out_path)[source]

Export telomere/centromere intervals to a GATK-readable chr:start-end file.

Written to a stable path (not a temp file) so the same file used by GATK -XL can be read back during reconciliation to define the excluded region exactly.

telomeres_and_centromeres is a BED import, so its intervals are half-open [start, end), while GATK reads chr:start-end as 1-based inclusive on both ends. Emit end - 1 so the file covers exactly the interval.

Parameters:

out_path (str) – Destination path for the intervals file.

gnomad_qc.v5.variant_qc.isolation_forest.merge_iforest_result(run_prefix, out_vcf_name, model_id, scatter_count, n_partitions, header_path, array_elements_required, transmitted_singletons, sibling_singletons, adj)[source]

Merge the per-mode scored VCFs into a single variant QC result HT.

The SNP-pass VCF contributes SNP alleles and the INDEL-pass VCF contributes all non-SNP alleles, so the union covers every scored allele exactly once.

Only the current run’s scatter_count shards are read (by explicit index), so a rerun with a smaller scatter count does not pick up stale shards from a prior run.

Parameters:

  • run_prefix (str) – GCS prefix for this run’s GATK outputs.

  • out_vcf_name (str) – Base name used for scored VCF shards.

  • model_id (str) – Isolation forest model ID (starts with if_).

  • scatter_count (int) – Number of score shards per mode (must match the scoring run).

  • n_partitions (int) – Number of partitions for the imported HTs.

  • header_path (Optional[str]) – Optional VCF header file for import.

  • array_elements_required (bool) – Value passed to hl.import_vcf.

  • transmitted_singletons (bool) – Whether transmitted singletons were a training set.

  • sibling_singletons (bool) – Whether sibling singletons were a training set.

  • adj (bool) – Whether the singletons VCF used adj genotypes.

Return type:

Table

Returns:

Merged variant QC result HT.

gnomad_qc.v5.variant_qc.isolation_forest.reconcile_scored_sites(sites_only_vcf, contigs, exclude_intervals_path, scored_ht, array_elements_required=False)[source]

Raise if any input variant in the scored region is missing from the output or unscored.

GATK writes every input record within its interval to the scored VCF, so any variant absent from the merged output was dropped (e.g. a truncated shard). GATK classifies every allele as either SNP or INDEL, so every variant should also carry a SCORE.

Input and output are both split, so variants are compared on the full key.

Parameters:

  • sites_only_vcf (str) – Input sites VCF that was scored.

  • contigs (List[str]) – Calling contigs passed to GATK (-L).

  • exclude_intervals_path (str) – Telomere/centromere exclusion file passed to GATK (-XL).

  • scored_ht (Table) – Merged scored result HT.

  • array_elements_required (bool) – Value passed to hl.import_vcf for the input.

Return type:

None

Returns:

None.
